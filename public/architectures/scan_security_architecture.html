Remediation boundaries

The fix workflow supports gateway rebinding, config permission tightening, safeBins insertion, and disabling detected auth-bypass flags. It creates a timestamped backup before edits. API key relocation is intentionally surfaced as a manual action because automatic secret migration is risky. The script does not implement automatic rollback, comprehensive post-fix verification, or transactional multi-file updates.
